## Rules for AI agents in this branch

1. Don't create commits without having confirmation from the user
2. Don't eliminate content without having confirmation from the user
3. Don't change the existing files without having confirmation from the user
4. Write as little code as possible
5. Always give a explanation about the changes created
6. Always make a simple index when an agent makes changes
7. Whenever a change is made it should be specified as a md in the /agent_logs folder, the format should be the same as the example in the folder.
8. Don't modify README.md without the user's explicit confirmation.
